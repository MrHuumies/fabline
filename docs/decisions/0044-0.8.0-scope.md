# ADR 0044 — 0.8.0 scope: spatial grammar and stochastic faults

- **Status:** accepted; owner approved both surfaces; spatial pilot mixed (0097); fixed-grid baselines next
- **Date:** 2026-11-28
- **Related:** RFC 0033, RFC 0032, ADR 0043,
  [`roadmap-0.5.0-0.8.0.md`](../roadmap-0.5.0-0.8.0.md),
  [`coverage-map.md`](../coverage-map.md),
  [`factory-v0.6`](../../benchmarks/factory-v0.6/card.md)
- **Approved by:** owner (scope inclusion, 2026-11-28)

## Context

0.7.0 froze `factory-v0.6` as a sequential-crew challenge; the task is valid
but the learned baselines fail. Phase 2 communication (0096) is negative:
local no-report 28.4/0.92 vs local report 17.2/0.72. The communication line is
retired on the current layout.

The roadmap's 0.8.0 flagship is the spatial production grammar. The owner also
requested stochastic faults/POMDP, which ADR 0043 had deferred from 0.7.0.
Both address large coverage gaps: spatial/OOD/relational/routing, and
belief-state maintenance/calibration. The owner accepted the larger scope.

## Decision

1. 0.8.0 contains **two independent benchmark surfaces**:
   - `factory-v0.7`: spatial production grammar;
   - `factory-v0.8`: stochastic faults/POMDP.
2. The tiers are not mixed in one task, one expected summary, or one freeze
   review. Each has its own task cards, splits, gates, and expected summary.
3. The first implementation slice is the **spatial generator + layout-shift**
   task. Route control and scale transfer follow. The fault/POMDP tier follows
   the first spatial slice; it can run in parallel only if both stay
   independently scoped.
4. If one tier fails its validity gate, the other can still ship. Do not
   combine them into a half-finished task.
5. The spatial grammar is opt-in and procedural: width/height/obstacles, one to
   three lines, random offsets/orientations, splitters/mergers, shared
   resources. The default world hash and frozen v0.1–v0.6 assets are unchanged.
6. The fault tier is opt-in: stochastic onset, noisy sensors, hidden wear,
   inspect/repair/continue, and root-cause prediction. Fault-free hashes are
   unchanged when disabled; true latent state is in `info` for labels only.
7. Freeze `factory-v0.7` only after the spatial generator + layout-shift pass;
   freeze `factory-v0.8` only after the fault/POMDP gates pass. Independent
   freezes.
8. Generative layout/recipe remains conditional on a grammar audit and moves
   to 0.9.0+ unless it passes.

## First slice — spatial

- `SpatialGrammarConfig`: width/height, obstacle density, one to three lines,
  offsets/orientations, optional splitters/mergers.
- Deterministic seeded generation, canonical state, replay, item conservation.
- Layout-seed splits; no episode-level leakage.
- `layout-shift` throughput/bottleneck task; train base layouts, test held-out
  larger/random layouts.
- Baselines: mean/persistence, linear/GBDT, MLP, CNN, MPNN, Transformer.
- Gates: skill over mean, OOD gap and model ordering, deterministic generation,
  no leakage, no default-hash change.

## Second surface — stochastic faults/POMDP

- `StochasticFaultConfig`: hazard depends on wear/load/maintenance; sensor
  noise/drift; hidden wear/fault; correlated failures; inspect/repair/continue.
- Tasks: `fault-detection-noise`, `pomdp-maintenance`, `root-cause`.
- Baselines: GBDT, HMM, Kalman/particle, survival, conformal, belief RL, POMDP
  solver, causal discovery.
- Gates: detection skill over base rate; ECE ≤0.05 only with skill; control gain
  over threshold; deterministic seeds/hashes; no redundant views.

## First-slice pilot (2026-11-28)

0097 trained tabular models on 16×8/20×12/24×16 base layouts and tested on
32×24 spread, 24×20 random, and 24×20 obstacle layouts. Raw score has a strong
base fit (linear R² 0.983) but collapses on the large (−1.29) and obstacle
(−303) shifts; per-line normalization generalizes on the random shift (0.60)
but still fails large (−0.99) and obstacle (−18.8). No tabular model is robust.
`factory-v0.7` is not frozen. The next step is a fixed-size padded grid with
CNN/MPNN/Transformer baselines and a formal layout-shift pre-registration.

## Alternatives

- **Spatial only.** The original roadmap; rejected by the owner's request to
  include stochastic faults/POMDP.
- **Faults only.** Leaves the spatial/OOD gap open; not chosen.
- **Mix the two in one task.** Rejected: layout and belief state would confound
  each other and make negative results uninterpretable.
- **Inventory/quality first.** Deferred; optional closers only.
- **Generative layout first.** Conditional on the grammar audit; 0.9.0+.

## Consequences

- 0.8.0 is larger than a one-flagship release: two benchmarks and two freeze
  reviews.
- The spatial/OOD and belief-state gaps get direct tests.
- The one-flagship rule is relaxed by the owner; the tiers remain independent
  so a failure in one does not block the other.
- More implementation and review work; sequence the spatial slice first.
- `factory-v0.1`–`factory-v0.6` remain immutable; no default hash changes.
